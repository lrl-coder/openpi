x_t ← x_t + dt * v_t
02 CFRG 侧路可选
上一次动作后预测力

当前周期采样结束后，policy 调用 predict_force(observation, actions)。

缓存一步预测

保存整段预测力分布：prev_force_mu 与 prev_force_log_sigma。

下一周期真实力到来

用真实 force 和上一周期第 0 步预测计算因果力残差。

r = Σ (force - prev_mu[0])² / exp(2 * prev_log_sigma[0])
映射成引导强度

r 越大，force guidance 越强，但被 lambda_max 限幅。

lambda = lambda_max * r / (r + 6)
周期 k 输出动作

多步采样得到 actions_k，机器人执行动作 chunk 的前部。

F_phi 预测下一步力

缓存 mu_k[0] 与 sigma_k[0]，等待下一次真实力观测。

周期 k+1 计算 CFRG

真实力偏离一步预测时，下一次采样循环中的梯度引导会被放大，并增强观测力一致性约束。

核心直觉

推理阶段的力数据有两条通路：局部力历史直接作为 action expert 条件；CFRG 则用“上一周期一步预测力 vs 当前真实力”的残差， 门控以当前传感器力为锚点的近端一致性能量，并在采样循环里通过 F_phi 的 NLL 梯度修正 v_t。
