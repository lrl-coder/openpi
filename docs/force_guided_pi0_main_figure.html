A clean three-lane view of the model: slow force history grounds the VLM's semantic contact target, fast force history conditions action generation, and runtime contact tension gates force-guided flow matching.

Figure. The diagram is organized as three non-overlapping flows. The semantic lane builds a task-level force target (μ*, Σ*) from VLM prefix tokens enriched by slow force history. The action lane uses a fast force token to condition π0's action expert; the final action-token hidden states are read by both the flow head and Fφ. The runtime lane computes CST from measured force and the previous prediction, producing λ(τ) that gates a force-guided flow term. Arrows converge only at the guided sampler, making the feedback structure explicit without clutter.
